# つりじま すしレーン

子ども向けのスマホファースト学習釣りゲームです。

## 内容

- さんすう Lv1からLv20
- ローマじ Lv1からLv20
- 1レベル5問
- 学習画面は回転ずしのお皿演出
- さんすうでコインを獲得
- ローマじでチケットを獲得
- コインでつりざおを購入
- ローマじレベルでつりばを解放
- 魚ずかんは40種類
- 相棒ペンギンがさんすうレベルで進化
- 進捗はブラウザのlocalStorageに保存

## 実行方法

`index.html` をブラウザで開くと遊べます。

GitHub Pagesでもそのまま公開できます。

テストで全レベルを選びたいときは、URLの最後に `?test=1` を付けます。

## 公開先の想定

ゲーム専用アカウント `manabi-games` のGitHub Pagesで公開する想定です。

例:

`https://manabi-games.github.io/tsurijima-sushi-lane/`
